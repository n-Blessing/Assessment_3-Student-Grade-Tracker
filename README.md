# Student Grade Tracker

A simple web app for adding students, recording their grades, deleting students, and calculating the class average automatically.

## Live Demo

Hosted site: https://n-blessing.github.io/Assessment_3-Student-Grade-Tracker/

GitHub repository: https://github.com/n-Blessing/Assessment_3-Student-Grade-Tracker

## Features

- Add a student name and grade.
- Store each student as an object with `id`, `name`, and `grade`.
- Display all students in a table.
- Delete a student from the list.
- Recalculate the average grade after adding or deleting students.
- Validate that the student name is not empty.
- Validate that the grade is a number from 0 to 100.
- Highlight students who scored above the current average.
- Save student records in localStorage so they remain after refreshing the page.

## Technologies Used

- HTML
- CSS
- JavaScript

## Student Object Structure

```js
{
  id: number,
  name: string,
  grade: number
}
```

The `id` is generated by the app so each student can be identified uniquely, especially when deleting a student.

## How To Use

1. Open the hosted site.
2. Enter a student name.
3. Enter a grade between 0 and 100.
4. Click **Add Student**.
5. Use the **Delete** button to remove a student.

The average grade updates automatically whenever the list changes.
